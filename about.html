关于 DogNav

一个精心 curated 的导航站点，收录优质网站，为你节省找网址的时间。

这是什么

DogNav（狗狗导航）是一个静态导航网站，收录了影视、软件、工具、资讯等多个分类的优质网站链接。所有链接经过人工筛选，确保每个站点都值得收藏。

本站托管在 GitHub Pages，无需服务器，永久免费。

技术栈

纯 HTML + CSS + JavaScript 构建，采用现代玻璃拟态（Glassmorphism）设计风格。无框架依赖，无构建工具，代码简洁高效。

响应式布局适配手机、平板、桌面端。支持多引擎搜索、分类筛选、心形点击动效等功能。
