## Features

- **146+ curated sites** across 10 categories, hand-picked for quality
- **Glassmorphism UI** with dark/light theme toggle
- **Smart search** supporting Baidu, Google, Bing, GitHub, Bilibili, and Zhihu
- **Category filtering** with smooth animations
- **Fully responsive** — works on desktop, tablet, and mobile
- **Zero dependencies** — pure HTML/CSS/JS, no frameworks
- **China-friendly** — all resources accessible from mainland China

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — glassmorphism design, CSS Grid, custom properties, animations
- **Vanilla JavaScript** — no frameworks, no build tools
- **Font Awesome** — icon library (self-hosted)
- **Google Fonts** — Sora + Noto Sans SC
